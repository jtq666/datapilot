## 启动参考版

按上游项目说明准备它自己的模型服务配置；该配置与本项目默认的 Ollama + Qwen 运行链路相互独立。配置和凭据保存在本机，不提交到仓库。

```powershell
cd F:\shixi\data-agent-platform
.\scripts\run_full_platform.ps1 -Mode reference
```

同时启动参考版和本项目工作台用于对照：

```powershell
.\scripts\run_full_platform.ps1 -Mode both
```

独立实现的本地服务可以单独启动，不必启动上游：

```powershell
.\scripts\run_full_platform.ps1 -Mode target -SkipFrontend
```

启动脚本及端口发生变化时以脚本参数和终端输出为准。上游服务的可用性只证明参考环境能够启动，不证明 `data_platform/` 具有相同的产品覆盖范围。
